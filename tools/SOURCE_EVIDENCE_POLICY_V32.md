# V3.2 evidence policy

A structural match is not verified retrieval. Preserve actual source URLs, observed JST timestamps, extraction method, field-level observations and retrievable evidence references. Never reconstruct an alleged source excerpt from an existing ledger or prior assistant report. Missing original evidence requires revalidation; do not promote pending records to publication or training. Count distinct providers separately from demonstrated independent upstream origins. Search excerpts with missing rows must not be treated as complete results. Store field-level disagreements separately; missing optional fields are not agreement. Keep previous records for audit and append corrections rather than silently replacing evidence. Test fixtures are excluded from acquisition metrics.
